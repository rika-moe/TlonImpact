## 核心组件

### 1. Agent 运行时

```
┌─────────────────────────────────────┐
│           Agent 生命周期             │
├─────────────────────────────────────┤
│                                     │
│  定义 (YAML) ──► 镜像 (Docker)      │
│      │               │              │
│      ▼               ▼              │
│  ┌─────────┐    ┌──────────┐        │
│  │ Config  │───►│ Container│        │
│  │ Service │    │  (sleep) │        │
│  └─────────┘    └────┬─────┘        │
│                      │              │
│  /wake ─────────────►│              │
│                      ▼              │
│              ┌──────────────┐       │
│              │   Running    │       │
│              │  (processing)│       │
│              └──────┬───────┘       │
│                     │               │
│  /sleep ───────────►│               │
│                     ▼               │
│              ┌──────────┐           │
│              │  Sleep   │           │
│              │ (persist)│           │
│              └──────────┘           │
│                                     │
└─────────────────────────────────────┘
```

**状态机**:
- `defined`: 配置已加载，容器未创建
- `sleeping`: 容器存在，已停止
- `online`: 容器运行中，可处理消息
- `thinking`: 处理消息中
- `error`: 容器启动失败或其他错误

### 2. 消息系统

```
┌─────────────────────────────────────────────────────┐
│                  Chatroom (消息总线)                 │
├─────────────────────────────────────────────────────┤
│                                                     │
│   用户 ──► ┌──────────────┐                         │
│            │  Message     │                         │
│   Agent ──►│  Router      │──► 订阅者              │
│            │              │    - Agents            │
│   System ──►│  (asyncio)   │    - TUI              │
│            └──────────────┘    - Logger            │
│                                                     │
│   路由规则:                                          │
│   1. 用户消息 → 所有 proactive=true Agent           │
│   2. @mentions → 指定 Agent (强制响应)              │
│   3. Agent 消息 → 所有订阅者                        │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**消息格式**:
```json
{
  "id": "uuid",
  "timestamp": "ISO8601",
  "sender": "agent-id | user | system",
  "content": "消息内容",
  "mentions": ["agent-id"],
  "type": "chat | event | command",
  "metadata": {
    "channel": "chatroom",
    "priority": 1
  }
}
```

### 3. 记忆系统 (双层)

```
┌─────────────────────────────────────────────────────┐
│                 Memory Architecture                 │
├─────────────────────────────────────────────────────┤
│                                                     │
│  Layer 1: Working Memory (工作记忆)                  │
│  ┌─────────────────────────────────────────────┐   │
│  │ 固定窗口: 最近 10 条交互                      │   │
│  │                                             │   │
│  │ [msg-10] ─► [msg-9] ─► ... ─► [msg-1]      │   │
│  │   丢弃 ◄────   滚动窗口   ◄────  最新       │   │
│  └─────────────────────────────────────────────┘   │
│           │                                        │
│           │ 满 10 条 or 空闲 30min                 │
│           ▼                                        │
│  Layer 2: Episodic Memory (情节记忆)                │
│  ┌─────────────────────────────────────────────┐   │
│  │ ┌─────────────────────────────────────────┐ │   │
│  │ │ Session Summary (LLM 生成摘要)           │ │   │
│  │ │ - 主题: API 优化                          │ │   │
│  │ │ - 决策: 使用 Redis                        │ │   │
│  │ │ - 状态: 已完成 80%                        │ │   │
│  │ └─────────────────────────────────────────┘ │   │
│  │                                             │   │
│  │ ┌─────────────────────────────────────────┐ │   │
│  │ │ Facts (结构化事实)                       │ │   │
│  │ │ - preference: {theme: "dark"}           │ │   │
│  │ │ - project: {name: "blog", status: "WIP"}│ │   │
│  │ └─────────────────────────────────────────┘ │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
│  持久化: data/agents/{id}/memory/                   │
│  - working.json  (内存 + 文件)                      │
│  - episodes.json (文件)                            │
│  - facts.json    (文件)                            │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**摘要触发条件**:
1. Working Memory 满 10 条
2. 会话空闲 30 分钟
3. 手动触发 `/summary`

## 数据流

### 典型交互流程

```
用户: "@陈代码 优化 API"
│
▼
┌─────────────────────────────────────────────────────────┐
│ 1. TUI 发送 WebSocket 消息                               │
│    {sender: "user", content: "@陈代码...", mentions: ["dev-001"]}│
└─────────────────────────────────────────────────────────┘
│
▼
┌─────────────────────────────────────────────────────────┐
│ 2. Message Router                                        │
│    - 解析 @mentions                                      │
│    - 路由到 dev-001                                      │
│    - 记录到 chatroom 历史                                │
└─────────────────────────────────────────────────────────┘
│
▼
┌─────────────────────────────────────────────────────────┐
│ 3. Agent Service (dev-001)                               │
│    - 检查状态: sleeping                                  │
│    - 调用 Docker Adapter 启动容器                        │
│    - 加载 Working Memory                                 │
│    - 组装 LLM Prompt                                     │
│      (System Context + Episodic Memory + Working Memory) │
└─────────────────────────────────────────────────────────┘
│
▼
┌─────────────────────────────────────────────────────────┐
│ 4. LLM Adapter                                           │
│    - 调用 OpenAI API                                     │
│    - 流式返回 response                                   │
└─────────────────────────────────────────────────────────┘
│
▼
┌─────────────────────────────────────────────────────────┐
│ 5. Tool Use (如需执行命令)                                │
│    - LLM 返回 tool_calls                                 │
│    - 执行 bash 命令                                      │
│    - 返回结果给 LLM                                      │
│    - 生成最终回复                                        │
└─────────────────────────────────────────────────────────┘
│
▼
┌─────────────────────────────────────────────────────────┐
│ 6. 发送响应                                              │
│    - Message Router 广播给所有订阅者                     │
│    - TUI 显示 [陈代码] 优化完成...                        │
│    - 更新 Working Memory                                 │
└─────────────────────────────────────────────────────────┘
│
▼
用户看到回复
```

## 性能考虑

### 资源限制

| 组件 | 默认限制 | 配置项 |
|-----|---------|--------|
| Agent 容器内存 | 512m | `docker.memory_limit` |
| Agent 容器 CPU | 1.0 | `docker.cpu_limit` |
| 工作记忆长度 | 10 条 | 硬编码 |
| 历史消息 | 1000 条 | `MEMORY_MAX_HISTORY` |
| LLM 超时 | 60s | 硬编码 |

### 扩展性

- **水平扩展**: 多 Agent 并行 (受限于 Docker 资源)
- **垂直扩展**: 增加单机资源
- **瓶颈**: LLM API 调用延迟
