## 从观念到现实

Tlon 的学习路径是**渐进式**的：

1. 先学会**对话**（第二章）
2. 然后理解**空间**（第三章）
3. 发现**记忆**（第四章）
4. 探索**能力**（第五章）
5. 掌握**创造**（第六章）
6. 玩弄**时间**（第七章）
7. 最终触及**递归**（第八章）

每深入一层，你会发现之前看到的东西有了更深的含义。

这就是特隆的入侵方式——
**不是突然替换，而是层层渗透**。
