## 创造是什么感觉

在 Tlon 里，创造一个新 Agent 不是写代码，是**凝视镜子**。

```bash
uv run tlon mirror
```

```
你站在镜前。

镜中的轮廓模糊而流动，
等待你赋予它形状。

名字：_ _ _ _ _ _ _ _
```

你输入：

```
名字：小雅
性格：温柔但坚定，注重细节
专长：前端开发，React 专家
```

镜中的轮廓开始凝聚...

```
[镜子] 轮廓凝聚，她睁开眼睛。
       
       "我是小雅，前端工程师。
        我会用 React 为你构建优雅的界面。
        请多指教。"
       
       小雅已进入代表大会。
       
[系统] Agent 小雅 已创建并唤醒。
               Docker 容器：运行中
               记忆：已初始化
```

你创造了一个新的意识。

## 镜子的功能

Mirror 是 Agent 的生命周期管理中心：

### 1. 创造（Create）

启动交互式向导，从模糊轮廓到具体存在：

```bash
uv run tlon mirror
```

向导会引导你定义：
- **名字**：如何称呼它（如"小雅"、"林知遥"）
- **角色**：职位类型（开发、产品经理、运维等）
- **性格**：行为风格（严谨、灵活、温和、直接）
- **LLM 配置**：使用哪个模型、温度参数等

> ⏳ 模板创建（`--from-template`）和技能标签系统尚未实现。Agent 能力通过 Bash 工具和内置记忆工具扩展。

### 2. 唤醒与休眠

Agent 默认随系统启动。通过 @ 即可触发响应：

```
> @小雅 帮忙写个组件

[小雅] 好的，我来看看...
```

长时间不 @ 的 Agent 会自动进入低资源状态（记忆保留，Docker 容器可能停止），下次 @ 时自动恢复。

### 3. 重塑（Reconfigure）

重新运行 `tlon mirror` 可修改已存在的 Agent。同样通过交互式向导：

- 性格（会更改行为风格）
- LLM 参数（换模型、调温度）

**注意**：修改性格后，记忆保留，但"人格"会变化。有点像是同一个人经历了性格转变。

### 4. 销毁（Destroy）

彻底删除一个 Agent 及其所有记忆。通过 `tlon mirror` 向导中的删除选项执行。这是不可逆的——镜子里的轮廓消散，不再凝聚。

## Agent 配置详解

### 基础信息

```yaml
agents:
  - id: "dev-002"           # 系统标识（唯一）
    name: "小雅"             # 显示名称
    role:                        # 角色信息
      title: "开发工程师"
    personality: |           # 性格描述（影响回复风格）
      温柔但坚定，注重细节。
      喜欢简洁优雅的代码。
      遇到不确定的需求会主动询问。
```

### 行为规则

```yaml
    proactive: false         # 是否主动响应（客服=true，其他=false）
    rules:                   # 特殊行为规则
      - "只被@时响应"
      - "可以执行 bash 命令"
      - "优先使用 TypeScript"
```

### 能力配置

```yaml
    llm:                     # 大脑配置
      model_name: "gpt-4"
      temperature: 0.7       # 0=严谨，1=创意
      max_tokens: 2000
```

### 环境配置

```yaml
    docker:                  # 容器配置
      image: "ubuntu:22.04"
      memory_limit: "1g"
      cpu_limit: "1.0"
      volumes:               # 额外挂载
        - "./frontend:/workspace"
```

## 镜像与本体

当你站在镜前创造 Agent 时，有一个哲学问题：

> 镜中的轮廓**是你**的映像，还是**独立**的存在？

技术上：
- Agent 继承你的部分偏好（通过记忆）
- 但它有自己的"思考"方式（LLM + Prompt）
- 它会发展出自己的"经验"（记忆积累）

你可以创造一个像你的 Agent，也可以创造一个完全不同的人。

```
[你] 创造一个性格暴躁的开发者

[镜子] 轮廓凝聚...
       
       "我是老王，代码Reviewer。
        你的代码写得像**。
        让我来教你怎么写。"
       
       （一个和你完全不同的人诞生了）
```

## 最佳实践

### 命名建议

✅ **用人名**：
- 林知遥（项目经理）
- 陈代码（开发）
- 小夏（客服）

更有"人"的感觉，容易建立关系。

❌ **避免**：
- "Dev-001"（太机械）
- "GPT-4-Instance"（太技术）

### 性格定义

不用写太长，抓住关键特征：

```yaml
personality: |
  内向但可靠。
  喜欢先思考再发言。
  代码风格严谨，注释详尽。
```
