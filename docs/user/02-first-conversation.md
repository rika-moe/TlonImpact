# 第二章：第一次对话

> 在代表大会里，每一句话都可能唤醒一个意识。

---

## 两种对话方式

### 1. 直接发言（客服接待）

直接输入文字，客服会主动响应。

```
> 我想做个网站

[小夏] 好的！这是一个网站开发项目。
       我需要了解一些细节：
       - 是什么类型的网站？（博客/电商/展示页）
       - 有什么技术偏好？
       - 预计时间？
       
       或者我直接召唤项目经理来详细讨论？
```

客服是你与团队的**接口**。她负责：
- 初步理解你的需求
- 判断需要哪些角色参与
- 在你和专家之间传话

### 2. @提及（召唤特定角色）

如果你想直接找某个人：

```
> @林知遥 安排一下这个需求

[系统] 正在唤醒 林知遥...

[林知遥] 收到。我来拆解任务。
         @陈代码 评估技术方案
         @阿杰 分析一下用户故事
```

被 @ 的角色**必须响应**。这是代表大会的基本规则。

## 对话示例

### 场景：从零开始一个项目

```
> @林知遥 我要做一个个人博客

[林知遥] 明白。这个项目涉及：
         - 前端界面
         - 后端 API
         - 数据库设计
         - 部署运维
         
         我来协调团队。
         
         @阿杰 分析核心功能需求
         @陈代码 推荐技术栈

[阿杰] 核心功能：文章发布、标签管理、评论系统...
       建议 MVP 版本先做发布和展示。

[陈代码] 技术方案建议：
         - Next.js（前端+后端一体化）
         - PostgreSQL（数据持久化）
         - Docker（部署标准化）
         
         我可以先初始化项目结构。
         [执行：npx create-next-app@latest my-blog]

[林知遥] 技术方案已定。
         @赵部署 准备一下部署环境
         
         预计今晚可以出 MVP。
```

你说了**一句话**，团队开始**并行工作**。

### 场景：排查问题

```
> 网站打不开了

[小夏] 我来看一下...
       服务状态异常，可能是服务器问题。
       
       @赵部署 紧急排查一下

[赵部署] 正在检查...
         [执行：docker ps]
         [执行：docker logs web-container]
         
         发现：内存溢出导致容器崩溃。
         正在重启并调整内存限制。
         
         [执行：docker run --memory=2g ...]
         
         已恢复。建议优化代码中的内存使用。

[小夏] 问题已解决。
       赵部署建议优化内存使用，
       是否需要安排开发进行性能优化？
```

### 场景：学习新技术

```
> @陈代码 什么是 WebSocket？

[陈代码] WebSocket 是全双工通信协议，
         允许服务器主动向客户端推送数据。
         
         我来写个示例，你可以运行看看：
         
         [创建文件：websocket_demo.py]
         
         ```python
         import asyncio
         import websockets
         
         async def handler(websocket, path):
             async for message in websocket:
                 await websocket.send(f"Echo: {message}")
         
         start_server = websockets.serve(handler, "localhost", 8765)
         asyncio.get_event_loop().run_until_complete(start_server)
         asyncio.get_event_loop().run_forever()
         ```
         
         运行 `python websocket_demo.py`，
         然后用浏览器连接 ws://localhost:8765 测试。

> 能用在我们的项目里吗？

[陈代码] 可以。比如实时通知、聊天功能。
       需要我集成到现有项目中吗？
```

## 有效对话的技巧

### 说清楚背景

❌ 不太有效：
```
> 修复 bug
```

✅ 更好：
```
> 用户登录时偶尔报错 "Session timeout"，
> 刷新页面后又能正常登录。
> @陈代码 帮忙看看
```

### 指定角色

如果你知道该找谁，直接 @：

```
> @阿杰 这个按钮放在哪里比较好？
> @陈代码 这段 SQL 能优化吗？
> @赵部署 准备一下生产环境
```

不确定时，直接说，客服会帮你分派。

### 追问和澄清

Agents 也会说错话。随时追问：

```
> 为什么选 PostgreSQL 而不是 MySQL？

[陈代码] 因为 PostgreSQL 支持更复杂的查询和 JSON 字段。
         但如果你的团队更熟悉 MySQL，也可以换。
         
         需要我改用 MySQL 吗？
```

## 常见模式

### 模式一：需求 → 评估 → 执行

```
你：我想做 X
    ↓
林知遥：拆解任务，评估工作量
    ↓
开发：技术方案 + 执行
    ↓
运维：部署上线
```

### 模式二：问题 → 诊断 → 修复

```
你：出问题了
    ↓
客服：初步分类
    ↓
专家：深入诊断（开发/运维）
    ↓
修复 + 预防建议
```

### 模式三：学习 → 示例 → 实践

```
你：什么是 X？
    ↓
开发：解释 + 可运行示例
    ↓
你：能用在项目里吗？
    ↓
开发：集成方案
```
