# 第一章：进入特隆

> 一个由观念构建的宇宙，正在等待你的唤醒。

---

## 你将经历什么

安装 Tlon 只需要几分钟。但接下来发生的事情，可能会改变你对"一个人开发"的理解。

你会获得：
- 一个永远在线的客服
- 一个帮你拆解需求的项目经理  
- 几个随叫随到的开发工程师
- 一个默默维护基础设施的运维

他们住在你的电脑里。他们记得你的一切。他们只在被需要时出现。

---

## 安装

### 前提

- Python 3.11+
- Docker（用于隔离执行环境）
- OpenAI API Key 或兼容的 LLM 服务

### 一键安装

```bash
pip install tlon
```

### 第一次唤醒

```bash
tlon wizard
```

向导会问你几个问题：
- 你的名字（他们会这样称呼你）
- API Key（用于驱动 Agents 的大脑）
- 默认团队配置（可以之后再改）

完成后，你会看到：

```
[镜子] 轮廓已凝聚。
       你的第一支团队已就绪。
       
       客服：小夏
       项目经理：林知遥
       开发：陈代码
       运维：赵部署
       
       输入 `tlon` 进入代表大会。
```

---

## 启动方式

### 方式一：完整体验（推荐）

两个终端：

```bash
# 终端 1：启动核心服务
tlon server

# 终端 2：启动交互界面
tlon tui
```

你会进入 TUI（终端用户界面），看到代表大会的实时对话。

### 方式二：快速体验

```bash
tlon
```

嵌入式模式，适合快速试用。所有功能可用，但退出后服务停止。

---

## 验证安装

启动后，输入：

```
> 你好
```

如果看到类似这样的回复，说明一切正常：

```
[小夏] 您好！我是客服小夏。
       我随时准备记录您的需求，
       并协调项目经理和开发团队。
       
       有什么可以帮您的吗？
```
