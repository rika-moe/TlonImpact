# Tlon WebUI 设计方案

> 现代化 Web 界面设计文档

---

## 1. 设计原则

### 1.1 核心理念

- **简洁现代**：参考 Discord、Claude、Linear 的交互模式
- **Web 原生**：充分利用 Web 技术特性（链接分享、多标签、响应式）
- **博尔赫斯美学**：融入 Tlon 品牌调性（特隆宇宙的诗意与神秘）

### 1.2 布局范式

采用 **Sidebar + Header + Main Content** 三栏布局：

```
┌─────────────────────────────────────────────────────────────────────────┐
│  🐙 Tlon                                          [🔔] [👤] [⋯]          │  ← Header
├──────────┬──────────────────────────────────────────────────────────────┤
│          │                                                              │
│  Sidebar │                    Main Content Area                         │
│  (80px)  │                  (Chat / Events / Agents)                    │
│          │                                                              │
└──────────┴──────────────────────────────────────────────────────────────┘
```

## 2. 构建方案

### 2.1 目录结构

```
tlon/
├── web/                          # 前端源代码（独立目录）
│   ├── src/
│   ├── package.json
│   ├── vite.config.ts
│   └── dist/                     # npm run build 输出
├── src/tlon/webui/               # 复制后的静态文件（gitignore）
├── scripts/
│   └── build.sh                  # 构建脚本
└── pyproject.toml
```

### 2.2 构建流程

使用 bash 脚本构建（不依赖 hatchling 钩子）：

```bash
# scripts/build.sh
#!/bin/bash
set -e

echo "🔨 Building WebUI..."

# 1. 编译前端
cd web
npm ci
npm run build
cd ..

# 2. 复制构建产物到 Python 包
rm -rf src/tlon/webui
mkdir -p src/tlon/webui
cp -r web/dist/* src/tlon/webui/

echo "✅ WebUI built to src/tlon/webui/"

# 3. 使用 uv 构建 Python 包
echo "📦 Building Python package..."
uv build

echo "🎉 Build complete!"
```

### 2.3 pyproject.toml 配置

```toml
[tool.hatch.build.targets.wheel]
packages = ["src/tlon"]
artifacts = ["src/tlon/webui/**/*"]

[tool.hatch.build.targets.sdist]
only-include = ["src", "web", "scripts", "config", "skills"]
```

### 2.4 开发工作流

```bash
# 前端开发模式（热重载）
cd web && npm run dev

# 完整构建（发布前）
./scripts/build.sh
```

## 7. 交互规范

### 7.1 动画时长

- 快速反馈：150ms（按钮点击、hover）
- 标准过渡：300ms（页面切换、抽屉展开）
- 复杂动画：500ms（模态框、Toast）

### 7.2 滚动行为

- Congress: 消息列表底部固定（新消息自动滚动）
- Monitor: 实时滚动，可暂停
- Agents: 标准滚动

### 7.3 加载状态

- 按钮：Spinner + 禁用状态
- 页面：Skeleton 占位符
- 数据：渐进式加载

## 9. 技术栈建议

### 9.1 前端

- **框架**: React 18 + TypeScript
- **构建**: Vite 5
- **UI 库**: TailwindCSS + [DaisyUI](https://daisyui.com/components/)
  - 使用 DaisyUI 组件美化页面（Button、Card、Modal、Dropdown 等）
  - 支持主题切换，与 Dark/Light 模式无缝集成
- **状态管理**: Zustand / Jotai
