# 首启初始社会

全新实例首次运行 `tlon dream` 时创建五位初始人物。安装 Python 包本身不操作用户数据目录；初始化在 ConfigService 读取成员前完成，不发送邮件、不调用 LLM。2026-10-31 的五人决策覆盖 [ADR 0036](../decisions/0036-initial-society.md) 的三十人清单、无向认识图和初始组织。

相生与相克各形成一个有向五节点环，不是 DAG。每位成员各有一个相生和相克出边、各一个入边。关系是为 Agent 创作的单向初始情感，不是历史事实、对方承诺或相互关系。爱体现欣赏、靠近和愿意倾听，恨体现有具体理由的抵触、不信任或厌烦；不授予权限、不强制支持反对，也不要求破坏别人。双方尚未实际通信，没有虚构的既往成果。倾向允许随交往改变。

五行与人格重心不构成职位、权限或工具分工。删除旧人物资源与初始组织声明，不新增运行时组织注册表或关系服务。

## 包内资料与实例数据

`src/tlon/initial_society/` 随 wheel/sdist 提供 manifest 与五位人物的中文 IDENTITY.md、SOUL.md、RULES.md，共十五个人格文件，不复制运行中的 ~/.tlon。

manifest 成员包含 key、name、background、element（wood/fire/earth/metal/water），不再有 organization。relations 是 source、target、kind（love/hate）、reason 的有向对象列表。先分配全部 m-UUID，再解析关系；种子键只用于关联资料，不是成员地址。未知端点、自指、重复边、错误的度数或未组成五节点环的图必须被拒绝。

人格职责见 [identity](identity.md)：IDENTITY 是自我定义，SOUL 是价值观、性格与初始爱恨倾向，RULES 是具体工作方式。情感写入 SOUL，随人格进入上下文；真实联系地址在 `workspace/CONTACTS.md` 中按需读取。联系簿每人只记录自己的两条出边，包含目标姓名、背景、本实例地址、明确方向及理由；不把入边当成自己的感情，不生成反向关系。CONTACTS 正文不自动注入系统提示，成员可用普通文件工具维护。没有动态关系状态机；后续人格与联系簿更新属于成员自己的资料维护。

## 创建与生命周期

bootstrap 先播种内置原型与技能，再初始化成员。五位全部复用“标准智能体”原型（L2），模型为成员级 `deepseek/deepseek-flash`，top_p=0.9。其余部署设置沿用 AgentConfig 默认值。API key 由用户在实例 `.env` 配置，不打包密钥。

`initial-society.json` 保存初始化状态、初始成员地址索引和未完成计划，SQLite 初始化锁互斥，`.initial-society-staging/` 暂存完整成员。未完成计划冻结地址、manifest 和人格；中断后继续原计划，已发布成员文件不覆盖。完成后重启或升级不再创建、补回或覆盖成员，也不应重新验证已经完成的历史人物计划。完成后保留地址索引，供首次模型配置定位初始成员；manifest 与人格计划不再承担运行职责。

已有成员配置（包括无效配置）、成员持久状态、共享邮件数据库或 WebUI 身份的实例跳过初始成员。不把已有三十人社会改成五人，不删除用户原型或成员。旧未完成关系计划不兼容、不迁移，损坏或不符合当前格式的未完成计划明确失败；不重新编号或静默丢弃计划。本次开发不触碰真实 ~/.tlon。

## 验证边界

测试覆盖精确人物和资源集合、相生相克方向与环、非法图拒绝、SOUL 与关系目标一致性、真实地址解析、首次创建、重启不覆盖、删除不复活、并发与中断恢复。wheel 检查五位人物的十五个人格文件并拒绝旧人物资源。完整质量门包含隔离 TLON_HOME 的真实 dream、HTTP 发信与 SQLite 收件箱断言，结束后清理临时实例及进程。

### 本次实现验收（2026-10-31）

主会话复核资源、关系方向和完成状态调用方后运行 `scripts/check_all.sh`，最终 12/12 全绿：单元 2453 passed / 130 skipped，集成 55 passed / 1 skipped，WebUI 116 项通过。另以隔离 TLON_HOME 起真实 dream，HTTP 列表恰为五人，十个联系人条目均为每人一爱一恨；HTTP 发信给汉密尔顿并直接查 SQLite 确认入箱，随后删除临时 home、停止监听。该冒烟验证初始化、寻址与持久化，不验证真实模型是否按情感行动。

过程中发现并修正：便携版与 bootstrap 测试遗留三十人断言；两份 SOUL 的目标简称与全名一致性检查不符；最初退休完成计划时误删了首次模型配置所需的地址索引。最终保留地址索引并覆盖模型配置、退休计划及重启场景，未改动真实用户实例。
