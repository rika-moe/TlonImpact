# Schema 与程序解析的内容缓存

重复装配成员时，同样的工具 schema 与模块源码会被反复处理。仅缓存不依赖成员状态的成功结果；不缓存 runtime、闭包、成员配置或实际调用的输入输出验证。

## Schema 定义校验

`admit_schema` 每次仍严格复制 JSON 值，检查类型、支持的关键词和输入闭合对象要求。只缓存 JSON Schema 元校验的成功结果，键为严格复制后的规范 JSON 文本；缓存不返回可变对象，异常不进入缓存。修改内容产生新键，布尔、整数与浮点数不因 Python 值相等而混淆。

## EDN 模块解析

`loads_all` 按完整源码缓存私有解析树，每次返回独立深拷贝，保留 Form、vector、Keyword 和 Symbol 的类型。使用标准库 deepcopy；不缓存模块链接和依赖 builtins 的静态校验，因此不同成员仍重新绑定各自闭包与状态。单表达式 `loads` 的语义和实现不变。

两处均使用标准库 LRU，最多 256 条，超过 65,536 字符的单项直接处理而不入缓存；限制为内部常量，不增加用户配置。缓存键不依赖路径或 mtime，文件修改立即使用新内容。回归验证缓存命中、修改失效、可变状态隔离、类型边界、错误拒绝、容量淘汰与大输入绕过。
