## 1. 产品定位

**Tlon Operator 不是给普通用户用的。**

它是给工程师、运维、系统管理员的专业工具。功能丰富、操作灵活、信息密集。

用户场景：
- 部署新的 Agent 到集群
- 排查某个 Agent 的运行异常
- 查看系统事件流和 Trace
- 调整 Agent 配置和参数
- 监控 Agent 资源使用

## 2. 设计哲学

### 2.1 工程师优先

- **信息密度高**：一屏显示尽可能多的信息
- **操作快捷**：丰富的快捷键，支持 Vim 模式
- **可配置**：布局、颜色、快捷键都可自定义
- **调试友好**：日志、Trace、性能指标随手可得

## 8. 快捷键系统

### 8.1 全局快捷键

| 快捷键 | 功能 |
|--------|------|
| `1` | Agents 视图 |
| `2` | Events 视图 |
| `3` | Logs 视图 |
| `4` | Traces 视图 |
| `5` | Config 视图 |
| `r` | 刷新当前视图 |
| `q` / `Ctrl+C` | 退出 |
| `?` | 显示快捷键帮助 |

### 8.2 Agent 树操作

| 快捷键 | 功能 |
|--------|------|
| `↑` / `↓` / `j` / `k` | 上下选择 |
| `Enter` | 查看详情 |
| `Space` | 展开/折叠分组 |
| `n` | 新建 Agent |
| `e` | 编辑配置 |
| `d` | 删除 Agent |
| `s` | 停止/启动 Agent |
| `l` | 查看日志 |

### 8.3 事件/日志视图

| 快捷键 | 功能 |
|--------|------|
| `f` | 设置过滤条件 |
| `/` | 搜索 |
| `n` / `p` | 下一个/上一个匹配 |
| `g` | 跳到最新 |
| `G` | 跳到最旧 |
