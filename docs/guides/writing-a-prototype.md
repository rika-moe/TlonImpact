# 编写原型

原型包含 v2 `behavior.tlon`、完整 `modules/` 源码及人格资料。工作流程写成普通函数，具体实例见 [模块程序指南](writing-a-module-program.md)。旧 v1 rules 和 run-loop 已删除。

先通过 workspace 的只读文档与标准库映射读取相关文件，再编写完整程序包、调用现有校验工具、根据错误修订。提案经 staging、完整依赖差异审阅与批准后发布；实例化只复制获批内容。

原型模板可以声明 `:parameters`。参数渲染同时覆盖行为和模块，实例化时移除模板声明并验证完整包。占位符不能隐藏缺失依赖或越过模块路径边界；运行时不解释参数。

`:execution` 声明实例的装置级别，模型与预算在成员部署配置中选择。现有成员或原型文件不会被播种过程覆盖，旧格式也不会自动转换。
