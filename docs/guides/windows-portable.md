# Windows 便携版

便携版的目标是下载 ZIP、解压、双击使用，不安装 Python、uv、Node 或 Docker。发行设计见 [ADR 0053](../decisions/0053-portable-windows-distribution.md)。构建与测试能力不等于 Windows 10/11 实机验收；具体可下载版本及验收情况以发布记录为准。

## 启动

1. 将发行 ZIP **完整解压**到本机固定磁盘上的可写文件夹，例如 `D:\Tlon`。不要直接在压缩软件中打开 EXE，也不要放在网络盘或 U 盘上运行。
2. 双击 `Tlon.exe`。服务就绪后自动打开默认浏览器；启动失败时按提示查看日志。
3. 首次使用在网页设置用户名，默认服务商为 DeepSeek、模型为 `deepseek/deepseek-flash`；填写 API Key，验证并保存配置，也可手动选择其他服务商和模型。模型调用需要网络及对应服务商的账户，便携版不包含模型额度。
4. 在邮件界面给成员发第一封信。Docker 不可用时不提供 Shell，但邮件和成员自己的 workspace 文件工具仍可使用。

程序资源位于 `runtime/`，首次启动会在 `Tlon.exe` 旁创建 `data/`。配置、密钥、成员、邮件和日志保存在 `data/`；便携入口不会读取原来的 `~/.tlon`，也不会因为当前工作目录或外部 `TLON_HOME` 改用另一份数据。

再次双击同一份程序会打开已有实例。关闭网页不会停止 Tlon，成员和定时任务仍可继续工作；从系统托盘选择「打开 Tlon」可重开网页，选择「退出 Tlon」才会停止服务。程序不会自行注册开机启动。

## 备份与移动

先从托盘退出 Tlon，等待退出完成，再复制整个 `Tlon` 文件夹。可以在另一位置或另一台受支持 Windows x64 电脑的本地固定磁盘上运行副本。运行中的数据库文件不能按此方式当作一致备份。

完整副本包含 API Key。不要将自己的 `data/` 放进公开发行包或发送给不可信的人。用户手动填写的外部文件路径及外部服务配置仍可能需要在新电脑调整。

## 手动升级

1. 先阅读新版发布说明，确认数据兼容要求；不要假设任意降级都安全。
2. 退出 Tlon，备份整个文件夹。
3. 在另一个空目录解压新版，使用新版 `Tlon.exe` 和完整 `runtime/` 替换旧程序资源，保留原来的 `data/`。不要只覆盖 EXE，也不要把新旧运行库混在一起。
4. 启动并检查成员与邮件仍在。

删除整个文件夹会同时删除程序和全部 Tlon 数据。默认浏览器的历史与缓存由浏览器管理，删除 Tlon 文件夹不会清除它们。

## 运行边界

- 服务只供本机浏览器使用，不提供局域网或公网访问。
- 文件夹必须可写，不能以静默改写其他目录的方式绕过权限问题。
- 关闭浏览器不等于停止模型调用；需要停止工作时从托盘退出。
- 修改已有成员的模型后，其生效时机以设置页提示为准；正在进行的任务不承诺改用新模型。

首次发行必须验证干净 Windows 环境、中文与空格路径、移动后启动、重复启动、异常退出、保留数据升级及真实模型通信。源码单元测试和托管 Windows Server CI 只能覆盖其中一部分。

## 构建与自动验收（维护者）

在 Windows x64 / Python 3.13 环境执行：

```bash
npm --prefix apps/webui ci
npm --prefix apps/webui run build
bash scripts/check_all.sh --windows-portable
```

该分组执行 Windows 类型与单元检查，在不安装开发依赖的构建环境中使用 PyInstaller 目录模式打包，再运行真实 EXE 验收。输出为 `dist/windows-portable/Tlon-windows-x64.zip`，内容只有 `Tlon.exe` 和 `runtime/`；Windows CI 成功后将 ZIP 作为工作流产物上传。

自动验收使用本机模拟模型服务验证实际 LiteLLM 请求和成员工作程序，不使用真实用户 API Key，也不表示外部服务商已人工验收。`--headless` 与 `--quit` 供自动验收管理进程；普通用户直接双击，无需命令行。

成员装配时的 Docker 连接探测在工作线程执行，避免不可用的 Docker 地址阻塞网页及实例控制；装配取消时仍会回收随后建立的客户端。冻结包测试以不存在的 Windows named pipe 模拟未安装 Docker，慢连接与取消行为由独立回归测试覆盖。
