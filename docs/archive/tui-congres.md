## 1. 产品定位

**Congress 只有一个功能：聊天。**

不是运维工具，不是调试面板，就是一个纯粹的对话界面。

用户打开 Congress，只需要做三件事：
1. 看到有哪些 Agent 可以对话
2. 发送消息
3. 看到回复

---

## 2. 设计哲学

### 2.1 极致简洁

- **无配置**：打开即用，零学习成本
- **无菜单**：不需要学习任何命令
- **无分栏**：单栏布局，像微信一样自然
- **无状态切换**：一个界面，所有功能

### 2.2 对话优先

- 70% 屏幕给消息流
- 输入框永远可见
- 实时打字效果
- Agent "正在输入..." 提示

---

## 3. 整体布局

```
┌─────────────────────────────────────────────────────────────┐
│  💬 Congress                                          [_][✕] │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  🤖 Dev (2)                                          16:32   │
│  ─────────────────────────────────────────────────────────  │
│  👤 帮我写个快速排序算法                                     │
│                                                             │
│  🤖 Dev                                                     │
│  好的，我来实现一个快速排序：                                 │
│                                                             │
│  ```python                                                  │
│  def quicksort(arr):                                        │
│      if len(arr) <= 1:                                      │
│          return arr                                         │
│      pivot = arr[len(arr) // 2]                             │
│      left = [x for x in arr if x < pivot]                   │
│      middle = [x for x in arr if x == pivot]                │
│      right = [x for x in arr if x > pivot]                  │
│      return quicksort(left) + middle + quicksort(right)     │
│  ```                                                        │
│                                                             │
│  这个实现的时间复杂度是 O(n log n)...                         │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│ 🤖 ▼ │ @Dev 帮我优化这段代码...                      [发送]  │
└─────────────────────────────────────────────────────────────┘
```

**三个区域：**
1. **顶部栏**：标题 + 在线 Agent 数量
2. **消息区**：滚动对话历史
3. **输入区**：Agent 选择器 + 输入框 + 发送按钮

## 4. Agent 选择器

### 4.1 下拉选择

点击输入框左侧的 `🤖` 图标展开 Agent 列表：

```
┌─────────────────────┐
│ 选择 Agent:         │
│                     │
│ 🤖 @Dev    (在线)   │
│ 👔 @PM     (在线)   │
│ 🧪 @Test   (空闲)   │
│ 📋 @Review (忙碌)   │
│                     │
│ ─────────────────── │
│ @All - 通知所有人   │
└─────────────────────┘
```

### 4.2 @Mention 快捷输入

在输入框中直接输入 `@` 触发补全：

```
@▓
┌─────────────────────┐
│ @Dev                │
│ @PM                 │
│ @Test               │
│ @Review             │
│ @All                │
└─────────────────────┘
```

**智能排序：**
- 空闲 Agent 排在最上面（能立即响应）
- 忙碌的 Agent 排在下面
- 离线的 Agent 灰色显示

## 5. 消息展示

### 5.1 消息类型

| 类型 | 样式 | 说明 |
|------|------|------|
| **用户消息** | 右对齐，蓝色气泡 | 我发送的消息 |
| **Agent 消息** | 左对齐，白色气泡，带头像 | Agent 回复 |
| **系统消息** | 居中，灰色小字 | "Dev 加入了对话" |
| **正在输入** | 左对齐，闪烁光标 | Agent 思考中 |

### 5.2 代码块渲染

代码块支持语法高亮、行号显示、一键复制、保存到文件。

### 5.3 思考过程（可选展开）

Agent 回复下方可展开显示思考过程，用户点击后展示详细推理步骤。

---

## 6. 输入交互

### 6.1 输入框

输入框行为：
- 默认选中上次对话的 Agent
- 支持多行输入（Shift+Enter 换行）
- Enter 发送
- 上下箭头浏览历史输入
- Tab 切换 Agent

### 6.2 快捷命令

输入 `/` 显示快捷命令：

| 命令 | 功能 |
|------|------|
| /clear | 清空对话 |
| /agents | 查看 Agent |
| /help | 帮助 |
| /quit | 退出 |

**就这四个命令。** 不需要更多。

---

## 7. 快捷键

**总共 5 个快捷键：**

| 快捷键 | 功能 |
|--------|------|
| `Tab` | 切换 Agent |
| `↑` / `↓` | 浏览输入历史 |
| `Enter` | 发送消息 |
| `Esc` | 关闭弹窗/退出 |
| `/` | 快捷命令 |

**不需要记，只需要 Tab 和 Enter。**

## 9. 技术实现

### 9.1 数据流

User Input → Congress TUI → WebSocket → Tlon Server → Agent → WebSocket → JSON → Render → User View

### 9.2 状态管理

- current_agent: 当前选中的 Agent
- messages: 消息历史
- input_history: 输入历史
- is_typing: Agent 是否在输入
- agents: 在线 Agent 列表
