# ADR 0054：EDN 解析与 JSON 编码的有限规模契约

状态：已接受（2026-10-30）。关联 #234。

保留整数 map key 和合法共享引用；有限规模内允许，超限明确报错。限制属于语言核心，独立于 evaluator fuel，不增加成员配置。此决策不将待验证线索认定为已确认漏洞，也不承诺覆盖所有 builtin 的资源消耗。

EDN 每次解析最多 1,048,576 个源码字符、100,000 个值节点、100 层容器及每张 map 256 对键值。重复键也计入键值对数。loads_all 的全部顶层 form 共用预算；缓存不能绕过限制。源码在解析前检查，节点和深度在递归前检查，map 在读取超额条目前检查，限制碰撞字典构造的最坏规模。超限抛带位置的 EDNParseError。

json-encode 最多展开 100,000 个值节点、100 层嵌套，输出最多 1,048,576 UTF-8 字节（含转义、标点和键）。共享对象每次出现分别计入；祖先循环仍拒绝。使用标准库编码，累计输出预算必须在完整输出分配之前检查；字符串先以无需复制完整字符串的方式计算编码大小，大整数在十进制转换前限制规模。超限抛 EvalError。

阈值是保守的语言工作负载边界，不是性能 SLA：当前 39 个可直接解析的内置 .tlon 最大 6,295 字符、803 节点、14 层嵌套及单 map 6 对（另 2 个含模板占位符，不直接解析），源码上限留有余量；map 的较小独立上限约束整数碰撞的平方开销，总节点上限约束多个 map。后续调整须依据真实程序需求和有界测量，修改契约及边界测试，不提供无限制开关。

验证正常共享引用、有限碰撞整数键、各限制边界、重复键、loads_all 累计额度、Unicode/转义大小和错误类型；执行项目全量质量门及独立临时实例邮件冒烟。

JSON 字符串及键必须可编码为 UTF-8，拒绝孤立 surrogate 并抛 `EvalError`；整数十进制转换仍受 Python 自身限制，转换失败统一为 `EvalError`。

编码使用有界归一化树后调用标准库，不实现第二套 JSON 编码器。字符串计量不复制内容；整数先用位长排除明显超额值，再以有界十进制临时字符串计量（临时字符串可能略超剩余额度，随后拒绝），最终完整输出始终不超过字节上限。
