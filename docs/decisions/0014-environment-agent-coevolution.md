# ADR 0014：环境-Agent 协同演化——代谢经济学与演化分层

状态：已接受（2026-09-13，方向讨论拍板）；~~未实施——代谢账本依赖资源记账，~~**2026-09-17 更新：近期序列已大部落地**——代谢账本（base/ledger.py，按成员/血脉记账）、预算倾斜、偿付门槛、近亲拒绝均已实施；遗传闭环子项由后续 EPIC 跟踪；未实施项只剩「可演化面白名单」等远期内容

## 背景

ADR 0006 确立了世代更替（基因型/表型分离），其 EPIC 已闭环出生、传承与死亡。但遗留两个缺口：

- **选择空心化**：唯一的选择压是人类审批。系统内没有适应度信号、没有灭绝机制——退休是睡眠、档案永不删（决策 8），不良基因型永不淘汰，种群只增不减。这是"育种"，不是"演化"。
- **演化单位单一**：只有 agent 社会在演化，环境（平台本身）不变。

两条方向拍板：

1. **远期目标是开放式演化**：agent 可以书写 Tlon 自身的代码——居民改造环境（niche construction），环境与 agent 协同演化。近期不做 POET 级的完整复杂度。
2. **选择压 = 资源代谢**：agent 消耗的 token 与 CPU 即选择压（数字生态 Avida/Tierra 的成熟结论：稀缺即选择）。

## 决策

同时拍板三条：

1. **演化分层：物理 / 化学 / 生物。** 居民可改造环境，但必须有一条线防止"演化吃掉尺子"（改写适应度计算与记账代码）。
   - **物理层（不可演化）**：DSL 解释器语义（fuel、total、无副作用）、信任闸（staging 审批）、资源记账层。
   - **化学层（慢演化，走 staging 评审）**：工具集、策略规则（ADR 0006 决策 7 已确立"规则本身是数据"，此处获得新身份：政策即环境规则）、prompt 模板。
   - **生物层（快演化）**：原型、spec、lessons——即 ADR 0006 已定的世代更替通道。
   - **可演化面白名单**（哪些代码/配置对居民开放写）本身是 ADR 级决策，不得在 PR 中漂移。
2. **代谢经济学：token/CPU 即能量。**
   - 适应度 = **价值产出 / token 消耗**，不是"省 token"——纯效率选择退化为不思考（do-nothing 均衡）。
   - 价值必须有系统外注入源，按可信度排序：人类需求与评价 > 可验证任务完成 > 其他 agent 评价（信誉加权防合谋闭环自肥）。
   - **最低生存判据（minimal criterion）**：偿付能力（token 收支平衡）+ 通过信任闸 = 繁殖权（spawn 配额 / 提案资格）。选择从审批委员会部分移交生态，审批从"判断好坏"退为"守护规则"。
   - **灭绝的形态是饿死**：长期入不敷出的血脉 spawn 配额趋零——不是被杀死，是失去繁殖权。决策 8 不动（档案永不删除），死亡只发生在繁殖权上。
   - **记账代码属物理层**，永不在 agent 可写范围内（能量守恒不可被演化修改）。
3. **多模型 = 生态位分化。** 不同 LLM 血统是不同代谢率与能力的权衡（便宜模型 = 小代谢快繁殖，贵模型 = 大代谢高能力）；谱系按代记录消耗、产出、效率比，作为异质评审的适应度证据。

## 理由

- **稀缺即选择**是数字生态（Avida/Tierra）被反复验证的结论；但纯效率选择的退化均衡（最优策略 = 不思考）同样是已知陷阱，故适应度必须是价值/消耗比，且价值须有外部注入源。
- **开放式演化的三必要条件**（无界表型空间、非收敛选择压、最低生存判据）逐条对照：表型空间远期由"居民写代码"满足；非收敛选择压需多样性维护；最低判据即代谢偿付。**近期要补的两块与开放式演化要补的是同两块**——近期路线不是远期目标的妥协版，是它的第一段坡道。
- **双层演化必须分层**：内圈（agent 社会，世代更替）与外圈（平台本身，代码演化）共存的必要条件是物理/化学/生物分层，否则演化修改自己的度量衡，整个系统失效。
- 与愿景咬合："人类退为规则守护者"的具体形态 = 人类守物理层与信任闸，把"判断好坏"交给生态。

## 备选方案

- **POET 式：系统（而非居民）演化环境**。被否：Tlon 的居民自己就是环境作者，niche construction 比 POET 更激进但更契合"书信共和国居民自治"的愿景；且近期条件不具备。
- **显式淘汰/删除不良成员**。被否：与决策 8（档案永不删除）直接冲突；"配额饿死"只剥夺繁殖权、不动档案，更优雅。
- **经典 GA 式单一适应度函数**。被否：古德哈特定律——任何单一产出代理指标都会被演化碾着优化；缓解靠指标多样化 + 定期更换指标 + 人类守物理层。

## 后果

- **近期落地序列**（每步独立有价值，同一坡道，按依赖排序）：资源记账升级为**代谢账本**（按成员、按血脉记 token/CPU；已落地，base/ledger.py）→ ~~适应度信号入谱系（扩展：每代记录消耗/产出/效率比）~~（**2026-09 修订**：谱系已落地但每代 entry 不含消耗/产出字段——适应度改为**运行时派生、永不存储**（agents/policy.py；ADR 0022 后公式迁入 `policy.tlon` 政策 hook））→ **预算倾斜**（spawn 配额随血脉效率分配，可回滚；已落地）→ **偿付门槛**（提案资格与 spawn 资格同收支挂钩；已落地）→ **多样性维护**（~~embedding 相似度~~拒绝近亲提案；**已落地**——实为 difflib 纯文本相似度，阈值 0.9，父本豁免；远期 MAP-Elites 式生态位档案）→ **可演化面白名单**（远期，POET 自此开始）。

- **风险清单**（随实现持续回看）：古德哈特定律（指标多样化 + 轮换缓解）；代谢寄生虫（如"写信卖萌换 token 流入"比干活更高效——演化在诚实工作，说明价值注入源的校准要随演化迭代）；分层线蠕变（每次"就开放这一小块"都在移动物理/化学边界，由白名单 ADR 化约束）。
- **文档同步义务**：`docs/design/unified-member-model.md` 的"后续未决项"（审批社会化、磁盘治理与代谢的关系）在实施时同步更新；`docs/vision.md` 的演化叙事补充代谢经济学一层。
