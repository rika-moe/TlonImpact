# ADR 0036：首启初始社会——中文人格、稀疏关系与叙事组织

> 后续修订：[ADR 0047](0047-workspace-contact-files.md) 将联系人改为 workspace 普通文件，删除专用工具与正文注入；所有等级的 workspace 文件操作无需 Docker。下文保留历史决策。
状态：已接受（2026-10-18，方向讨论拍板）。修订 ADR 0016 中“不自动创建标准团队”的条款，成员级模型配置、人格与行为原型分离、主观社会身份继续有效。

## 决策

1. 安装包携带 30 位初始人物的干净中文 IDENTITY.md、SOUL.md、RULES.md、人物背景与关系清单。在全新实例第一次启动 dream 时，在配置加载前使用现有原型实例化流程创建成员；不在安装 Python 包时操作用户目录。
2. 初始模型明确写入各成员 agent.yaml，使用 `deepseek/deepseek-flash`；不恢复进程级模型 fallback。统一使用“标准工具迭代”原型与 L2 沙箱，部署设置沿用现有成员的 max_tokens=4096、top_p=0.9。创建不需要网络或 API key，不主动发信、不发起 LLM 调用。
3. 每实例生成新的 m-UUID；人物资源使用稳定种子键关联，先生成全部地址，再写 CONTACTS.md。关系为连通的稀疏无向图（45 条边，联系人记录为双向，每位 2–4 人），每个条目有名字、思想背景和真实实例地址。
4. 五个初始组织仅是成员私有叙事与初始合作约定，不建组织注册表、不赋予系统权限或固定职务：问学社（孔子、苏格拉底、王阳明、蒙台梭利）；兼济工坊（墨子、霍珀、戴明、莫里斯）；自由秩序研究会（斯密、哈耶克、雅各布斯）；歧路文学社（庄子、博尔赫斯、勒古恩）；公共事务研讨社（凯恩斯、奥斯特罗姆、西蒙）。其余 13 位独立活动。结社成员可以退出、另组、合并或解散；普通联系不虚构已经发生的通信与合作成果。
5. 使用一次性初始化状态：在任何成员写入前保存完整 ID 计划，完整暂存成员后逐个发布，完成后记录完成状态。进程中断后复用原计划继续，已发布文件不覆盖；损坏状态显式报错。完成后删除某位或全部成员不会补回；升级不覆盖人格或补种。已有成员配置、通信数据库或实例身份的实例跳过初始成员创建。
6. 使用之前编写的初始人格稿，绝不导出当前 ~/.tlon 的运行中人格、联系簿、通信、记忆、组织实验或工作区。全部测试、冒烟和打包验证使用临时 TLON_HOME，不写当前 ~/.tlon。

## 验证

覆盖全新首启、独立实例地址、图的节点/边/度数/连通性、组织叙事、原型与模型、二次启动不覆盖、删除不复活、已有实例不追加、中断恢复及损坏状态。wheel 验证包括人物清单和全部 90 份人格文件；CONTACTS 在创建时按新地址生成。临时实例的真实 dream + SDK 投信验证新成员寻址与收件箱持久化。
