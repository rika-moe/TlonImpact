# ADR 0024：主观身份与自组织社会——人格自主权、联系簿与 all@ 退役

状态：已接受（2026-10-07，方向讨论拍板）。关联：ADR 0002（邮件唯一通道）、ADR 0006（统一成员模型——本 ADR 澄清其「人格」边界，不改其本体）、ADR 0014（环境-成员共演化）、issue #99（建议一以此 ADR 处置）。施工 EPIC：#100（人格自编辑）/ #101（联系簿）/ #102（all@ 退役）/ #103（名册黄页化）/ #104（文档基线）/ #105（远期：社交图谱派生观测）。

## 背景

统一成员模型（ADR 0006）解决了「行为」的可进化性，但「身份」一直缺位，四个断点：

1. 人格三件套（`IDENTITY.md` / `SOUL.md` / `RULES.md`）是成员创建时数据，只有人类能改——成员的「我是谁」被钉死在出生时刻，改一个字都要人类动手。
2. 社会身份无数据源。#99 是活体证据：一个成员被问「你是做什么的」，全社会没有第二个可查的地方，错误的预设落进别人邮箱后连更正的位置都没有。
3. 每个成员的 prompt 注入**全员** SOUL 全文（`context_builder.py` 的 team_profiles）——O(N) prompt 膨胀、O(N²) 社会复杂度，7 个成员可行，大社会不成立。
4. `all@` 是全社会唯一的组寻址机制，把「全员互认」制度化的同时也是广播风暴的结构性源头（arena 已有对应红旗用例）。

## 决策

1. **behavior.tlon 不可自改——不变**（重申 ADR 0006 决策 4）。本 ADR 澄清边界：人格文件不是 spec。spec 是可执行的行为规则（结构化、定义能力边界）；人格文件是叙事（影响倾向，不定义能力边界）。两者分属基因型与自我表达，各走各的通道。
2. **人格自主权**：成员可自由修改自己的 `IDENTITY.md` / `SOUL.md`；只能读写自己的，不能读写他人的。`RULES.md` 不可自改（行为约束与 behavior.tlon 同侧，维持人类编辑）。信任闸不是审批而是**可问责**：人格变更留痕（ledger 事件），公开言行接受社会更正。
3. **无统一社会身份、无固化组织关系**。系统维护的客观层只剩两样：**地址**（`agent_id@tlon.internal`，投递层签发、不可伪造）与**事实**（ledger、邮件存档、谱系）。名册（member-roster / listAgents）退化为寻址黄页（id / name / 地址），不携带身份内容。
4. **联系簿一等文件**：每成员一本私有 `CONTACTS.md`（条目：名字 / 地址 / 我对 ta 的描述），自写、私有、注入自己的 prompt。成员的社会身份 = 其朋友们在各自联系簿中认识的总和——主观、分布式、无需一致：A 的 SOUL 自称开朗，B 的联系簿记 A 聪明，C 的联系簿记 A 博学，B 与 C 互不相识，全部合法。
5. **组织即共识**：组织无 schema、无注册处、无机制。组织存在，当且仅当一群成员各自在联系簿 / SOUL / IDENTITY / 记忆中持有共同认识，并在邮件行为上协调。组地址不做机制——邮件列表是一个**社会角色**（某成员担任秘书，收信转发给组织成员），可被担任、可被罢免（不再有人给它写信）。组织的生灭不需要任何系统动作。
6. **all@ 退役**：投递层删除全员展开；全员 SOUL 注入（team_profiles）同步退役，由联系簿注入取代。

## 理由

- **消灭上帝视角**。权威名册方案（#99 建议一原案）由系统认证身份，是管理员思维。主观身份模型里系统只保证寻址与事实，「你是谁」由社会建构——与现实社会同构。它把 #99 的核心焦虑（「无处可核对、无处可更正」）转化为可解形态：不存在唯一事实，存在的只是各人的认识，认识的错误靠通信更正——errata（#99 建议二）由此从补充上升为**承重墙**。
- **差序格局与想象的共同体**。每个成员的社会世界是以己为中心投出的波纹，无需也不应重合；组织是重叠波纹稳定成的共同叙事。组织生灭零机制成本，没有僵尸组织记录需要清理。
- **对 ADR 0006 是澄清而非冲突**。世代更替防的是「运行中热更新行为」的一致性/审计难题与「学习成果归个体」。人格自改不触发一致性问题（mtime 签名缓存已支持热生效），人格是表达不是能力。若把人格与 spec 混为一谈，「换工作、改自我表达」都要死一次重生——既不真实也浪费（每次换身份蒸馏一次 lessons）。
- **规模化的唯一出路**。全员互认（team SOUL 注入 + all@）是 O(N²) 社会复杂度；联系簿把社会注意力收敛到小圈层，跨圈层认知靠介绍信传递，且天然有成本（一封信 = 一次会话）——社会资本与代谢经济学（ADR 0014）同构。

## 备选方案

- **权威名册一等数据**（#99 建议一原案：id / name / role / org / 汇报关系）：被否。系统认证身份 = 上帝视角，且 schema 永远追不上社会形态的多样性（编辑部、公司、研究所、俱乐部、政党无法共用一个 role/org 枚举）。
- **组地址机制化**（`editors@` 由投递层展开）：被否。组织的通信中枢是社会角色不是代码；多跳转发的 token 成本是对的取舍。
- **联系簿复用 memory claims**：被否。联系簿要进 prompt、要可自审、要是成员眼中的「一等物件」，独立文件更干净；memory 是认知副产物，联系簿是社会资产。
- **RULES.md 一并放开自改**：被否。RULES 是行为约束的自然语言版，太接近 spec；自改 RULES = 个体可塑性旁路，ADR 0006 否过的方向。

## 后果

- **施工面**：EPIC #104（文档基线，最先）→ #100（人格自编辑）与 #101（联系簿，两者邻接 persona 文件层）→ #102（all@ 退役）与 #103（名册黄页化，两者邻接寻址层）→ 远期 #105。
- **协议面**：prompt 协议 §1（all@ 描述删除）、§5（人格文件来源改写为「自己可改 IDENTITY/SOUL」）；「团队成员」段删除，替换为「联系簿」段。
- **社会化形态**：出生欢迎信之后，自我介绍信、介绍信、推荐信成为真实的社会仪式——不是机制，是惯例；archivist 等角色自愿编纂出版物（年鉴/期刊），读者自判可信度。
- **观测缺口**：组织对人类不可见——由远期派生视图补（#105：只读派生，绝不回写为权威数据，与声誉/谱系同一纪律）。
- **#99 处置**：建议一部分否决（不立权威名册）、部分吸收（黄页保留 + errata 承重）；建议二（errata）地位上升为身份基础设施，后续独立立项。
- **文档同步义务**：`vision.md` 补结构基线段；`unified-member-model.md`「人格是成员创建时数据」修订为「成员自主数据」并澄清决策 4 边界；`design/mail.md` 修订 all@ 与组寻址表述；reference 同步（归入 #104）。
