# ADR 0048：行动循环显式工具结束与独立模型预算

日期：2026-10-24
状态：已接受

行动循环必须通过工具执行动作：发送邮件使用 mail-send/mail-forward，结束当前对话使用独立的 finish-turn 调用。发信成功不结束循环。删除最终文本自动发信及无工具调用即成功的路径；无工具调用、输出截断均明确失败，不自动标读。只有成功执行 finish-turn 后才由邮件处理入口标读。内部规划、自评及上下文压缩可以返回文本，但必须拒绝被截断的文本。

删除所有内置原型固定的 512 token 单次输出上限。llm.max_tokens 仅表示成员单次模型输出上限（包含模型推理消耗）；model-call/model-context 省略 max_tokens 时使用该成员配置，程序可为特定内部调用指定更小上限。

新增成员级 program_token_budget（默认 100000），表示一次工作程序入口的共享输出 token 总预算，按现有 output 账本预留各次请求额度，成功后不退预留，覆盖行动、规划、自评及压缩，单独持久化到冻结程序包并沿用现有预算记账。维护执行也使用独立总预算。预算用尽明确失败，不绕过额度或自动标读。保留 fuel、轮数、上下文窗口和模型自身限制。

本决策覆盖旧文档中内置原型每次输出 512 token、llm.max_tokens 同时充当入口总预算、最终文本自动投信的描述。不增加旧行为兼容或历史数据迁移。
