# ADR 0052：删除生育社会门槛与自动导师抄送

日期：2026-10-28
状态：已接受，按用户明确决策实施

## 决策

删除原型近亲拒绝、血脉 fitness 配额倾斜、偿付资格、试用成员生育额度限制、试用成员工具屏蔽及自动导师抄送。成员的出生来源和背书不再决定能否提案、派生成员或必须抄送谁。

每个成员均可调用 `member-spawn` 和 `prototype-write`，普通程序与模型工具使用相同的宿主执行边界。发信只使用显式指定的 `to` / `cc`，不因 `spawned_by` 自动追加收件人。`spawned_by`、原型谱系、背书及用量观测保留为事实与审计数据，不构成资格等级。

保留三项资源硬限制：全局同时激活上限、最大派生深度、固定的每 `(spawner, run)` 配额。配额仍由宿主执行根归属、持久账本计数，默认分别为 8、3、2，不再乘倍率或按成员资格收紧。模型预算、执行期限、fuel、装置权限、身份校验和效果回执不变。

原型静态校验、完整模块包、staging、人类审批和 trusted 原型才能实例化的约束保留。相似程序允许独立提交，行为是否值得保留由人类审批判断。

## 删除边界

`tilt` / `solvent?` / `full-member?` 的消费者全部删除后，一并删除 `agents/policy.py`、政策专用词汇与数据类型、`TlonPaths.policy_file()`、对应引用和测试；不保留空政策系统、恒真资格判定、兼容参数或 fallback。已有 `policy.tlon` 不再被读取，不迁移或删除用户数据文件。

原型相似度扫描与仅供其使用的源码拼接辅助函数删除。自动导师 CC 的装配参数、运行时字段和发送路径删除。测试改为验证无背书的派生成员可提案、可用相同固定配额生育，显式收件人不被扩大，以及各资源硬限制和审批闸仍生效。

## 理由与后果

上述社会门槛缺少当前需求支撑，却增加全社会扫描、隐式收件人和多层资格判断。直接删除比将其搬入 Lisp 更简单，也避免把出生来源等同于权力或私人通信访问权。资源滥用继续由明确的宿主硬限制约束。

本决策覆盖 ADR 0014 的近亲拒绝及生育经济门槛、ADR 0022 的全部政策 hook，以及统一成员模型中的试用信任阶梯；历史记录保留，现行设计同步更新。Adam 的生命周期 Lisp 程序不属于该删除范围。

实施后执行完整 `scripts/check_all.sh`，主会话复核变更并运行真实 dream + SDK 邮件冒烟，验证持久收件箱并清理进程与临时数据。此次不进行 Git 操作。
