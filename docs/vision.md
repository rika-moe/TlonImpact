# Tlon 愿景：Agent 自进化

> 本文是全项目的方向锚点。方向性讨论对着本文校准，拍板后的修订直接改本文。

## 愿景

**让 agent 社会实现自进化**：不依赖人类修改代码，新的行为、新的能力、新的成员从社会内部生长出来，整个社会随时间变得更好。

判断标准只有一条：人类退得越远，社会是否依然进步。

## 哲学

### 行为即数据

进化要求基因型是可写的。如果 agent 的行为是代码，它就永远只能由人类修改；只有当行为变成**数据**，agent 才能阅读、书写、传递和修改自己的行为——自我改进才有可能。

因此 Tlon 用一门 DSL 描述 agent 的全部行为。这门语言被**故意**设计得受限：可停机、无副作用、只能组合已有机制。表达能力让渡给安全性——一门语言只有足够安全，才配交给 agent 自己书写。

### 书信共和国（Republic of Letters）

进化不发生在个体内部，而发生在种群之中。Tlon 的 agent 组成一个社会，社会的唯一公共通道是**邮件**：

- **开放**：成员凭名字相互寻址，新成员出生即可加入，无需改造任何既有成员。
- **沉淀**：信件持久、可检索、可流传。知识在书信中积累，而不是随会话蒸发。
- **平等**：人类不是系统的管理员，而是社会的一员，通过同样的信件参与、评价、影响。

书信共和国是历史上真实存在过的知识共同体——学者们靠通信完成同行评议与知识传播。Tlon 借这个隐喻，是因为它是人类已经验证过的、让知识社会自我改进的结构。

## 路线

不预设时间表，只定方向顺序：

1. **筑基**——行为可被描述，通信可以运转，社会能跑起来。
2. **闭环**——经验沉淀为知识，知识能改写行为，改进开始在系统内部发生。
3. **开放**——新能力、新成员由社会内部产生；人类从审批者退为规则的守护者。

每一步都先做最小端到端，再往上叠加；每一步扩张 agent 的自主权，都先回答"信任闸在哪"。与信任闸互补的是可问责：成员被问"你为什么这么做"时必须能给出有据可查的回答——信任来自可解释，这是人类敢于放权的前提（内置 skill `explain-decision`，见 [design/skills.md](./design/skills.md)）。

### 当前阶段的结构基线：统一成员模型

2026-08 拍板：**成员只有一种**；成员是基因型的**不可变表达**，行为更新不走"改自己的 spec"，而走**世代更替**——创建新 prototype → 派生新成员。进化发生在原型（物种）层面，学习的成果归种群不归个体；退休成员档案归档、永不删除。完整决策集（9 条）与模型现状见 [docs/design/unified-member-model.md](./design/unified-member-model.md)，决策记录见 [docs/decisions/0006-unified-member-model.md](./decisions/0006-unified-member-model.md)。

这条基线把"闭环"一步的含义校准为：经验沉淀为知识（记忆，已有），知识经反思与总结产出**原型提案**（staging），评审后派生新一代成员——行为更新与"新成员从社会内部产生"走同一条通道，而不是为个体单开一条热更新旁路。
