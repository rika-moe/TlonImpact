# 普通函数组合的生成、核验与修订

通过原型创建接口提交 `behavior.tlon` 和 `modules/` 下两份作者模块，再创建使用该原型的成员。宿主提供纯标准模块 `tlon.messages`；不要将其复制到作者源码中。成员仍须配置自己的模型与 provider 凭证。

邮件事件调用 `work.reply/handle`，依次调用 `work.writing` 的生成、核验、修订函数，最后将修订结果回信。三个模型调用共享本次入口的根预算和持久执行记录，不会创建 stage 会话，也不执行模型工具请求。核验是模型建议，不等同于事实证明。

`tlon.messages/user`、`assistant` 构造消息，`append` 返回追加后的新消息列表；全部是纯函数。模型调用显式传入消息和空工具集合，宿主绑定人格与系统规则。
