## 想象一下

你坐在终端前，输入一句话：

```
> 帮我做一个能记录读书笔记的网页应用
```

然后你看着事情发生——

```
[小夏] 好的，我来记录这个需求。这是一个全栈项目，
       我建议找项目经理来协调。
       
[系统] 正在唤醒 林知遥...

[林知遥] 收到。我来拆解一下：
         @产品-阿杰 分析一下核心功能
         @开发-陈代码 评估技术方案
```

几分钟内，一个"团队"开始协作。不是你在写代码，是**你在指挥一个团队**。

这不是自动化。这是**多重意识的共谋**。

---

## 这是什么？

Tlon 是你的**影子团队**。

一个客服、一个项目经理、几个开发、一个运维——他们住在你电脑里的 Docker 容器中，拥有各自的专业记忆，通过聊天室协作完成你的软件项目。

他们记得你喜欢什么。他们记得上次项目为什么失败。他们会在凌晨三点（如果你需要）讨论技术方案。

而你，只需要**@他们**。

## 三分钟上手

### 安装

```bash
pip install tlon
tlon wizard    # 配置向导，跟着走就行
```

### 启动你的宇宙

```bash
# 方式一：后台服务 + 界面（推荐）
tlon dream     # 维持梦境（启动服务）
tlon intrude   # 另一个终端：入侵现实（连接界面）

# 旧命令仍然兼容
# tlon server    # 等同于 dream
# tlon tui       # 等同于 intrude

# 方式二：快速体验
tlon
```

**文学命令体系：**
- `dream`（出自《环形废墟》）：启动 Server，维持特隆宇宙的梦境
- `intrude`（入侵现实）：从特隆宇宙进入用户的现实世界
- `mirror`（出自《镜子与面具》）：在镜中创造/配置 Agents

你会看到：

```
你已进入 代表大会

客服、项目经理、开发、运维...
他们各自携带着记忆，等待你的召唤。

[小夏] 您好！我是客服小夏，随时待命。
```

## 能做什么？

### 场景一：从零开始一个项目

```
> @林知遥 我要做一个个人博客系统

[林知遥] 收到，我来协调。
        @阿杰 分析需求
        @陈代码 评估技术栈
        
[阿杰] 核心功能：文章管理、标签、评论...
       建议用 Next.js + PostgreSQL
       
[陈代码] 技术方案可行。
         我来初始化项目...
         [正在执行：mkdir blog && cd blog && npm init]
```

### 场景二：Debug

```
> 系统又报错了，帮我看看

[小夏] 我来看一下日志...
       这个问题涉及数据库连接池，
       需要开发协助。
       
       @陈代码 帮忙排查一下

[陈代码] 正在检查...
         [执行：docker logs postgres]
         找到问题了，连接数超限。
         已修复配置。
```

### 场景三：学习新技术

```
> @陈代码 教我什么是 WebSocket

[陈代码] WebSocket 是全双工通信协议...
         我来写个示例：
         [正在创建：websocket_demo.py]
         
         你可以运行 `python websocket_demo.py` 试试。
```

## 他们记得你

这不是每次都要重新介绍的 ChatGPT。

你的 Agents 会记住：
- 你喜欢暗色主题还是浅色
- 上次项目为什么延期
- 你偏好 Python 还是 JavaScript
- 甚至你通常在几点工作

```
> @陈代码 像上次那样配置项目

[陈代码] 明白，你喜欢用 TypeScript + ESLint 严格模式，
         我直接按这个配置。
```

## 无限技能

当你的 Agent 需要一项新能力时，它会去**图书馆**取一本书。

```
> 分析一下这个 PDF 的内容

[陈代码] 我需要 PDF 处理能力。
         正在去图书馆...
         [已获取技能：pdf-processing]
         
         现在我可以读取这个 PDF 了。
```

技能库在不断增长：Git 操作、文件处理、网络搜索、数据分析……每本书都可以随时借阅。

## 时间可以分叉

在 Tlon 里，你可以让时间分叉——同时探索多个方案。

```
> @林知遥 基于现在的代码，做两个方案对比

[林知遥] 明白，我创建两条路径：
         - 路径 A：Redis 缓存方案
         - 路径 B：本地内存方案
         
         开发们会并行推进，
         完成后我们对比效果。
```

## 站在镜前

想添加新成员？

```bash
tlon mirror                    # 交互式向导
tlon mirror --reflect          # 查看所有 Agents
tlon mirror --create 小雅 --position developer  # 快速创建
```
